# Suivi Gravelman amélioré

Plugin WordPress du club BikeXplore : classement live d'un parcours d'une épreuve Gravelman
(ou de toute épreuve suivie sur DotVision), avec carte, coureurs suivis et détection des raccourcis.

Installation : télécharger `suivi-gravelman-ameliore.zip` depuis la [dernière version](../../releases/latest),
puis WordPress → Extensions → Ajouter → Téléverser. Mode d'emploi : [README.txt](suivi-gravelman-ameliore/README.txt).
